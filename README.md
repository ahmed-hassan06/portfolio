# Ahmed Hassan — Portfolio

My personal portfolio website: a responsive single-page site with About, Skills, Projects and Contact sections.

**Live site:** https://ahmed-hassan06.github.io/portfolio/

## Built with

- HTML5, CSS3 and vanilla JavaScript (no frameworks, no build step)
- [Font Awesome](https://fontawesome.com/) icons and the Inter font (loaded from CDNs)

## Run locally

Open `index.html` in any modern browser. An internet connection is only needed for the font and icon CDNs.
